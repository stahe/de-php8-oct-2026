    22. Praktische Übung – Version 11

    Es ist nach wie vor üblich, dass Webservices ihre Antwort als XML-Dokument statt als JSON-Dokument senden:

    • Das JSON-Dokument ist kleiner, aber man braucht Anweisungen, um es zu verstehen;
    • Das XML-Dokument ist ausführlicher, aber selbstbeschreibend. Es ist sofort verständlich.

    Wir ändern die Client-Server-Anwendung aus Version 10 so, dass der Server seinen Clients nun ein XML-Dokument als Antwort sendet. Damit setzen wir das vorherige Kapitel in die Praxis um.

    <?php

declare(strict_types=1);

// Namespace
namespace Application;

// Hilfsfunktionen für das XML-Format: die Klasse kann weder instanziiert noch abgeleitet werden
final class XmlUtilities
{
    // privater Konstruktor: die Klasse kann nicht instanziiert werden
    private function __construct()
    {
    }

    // gibt das XML-Dokument eines Arrays [$data] zurück: das Wurzelelement heißt [$root]
    // die Schlüssel des Arrays werden zu Elementnamen, die Werte zu deren Inhalt
    public static function arrayToXml(array $data, string $root): string
    {
        // ein leeres XML-Dokument (neue DOM-API von PHP 8.4)
        $document = \Dom\XMLDocument::createEmpty();
        // das Dokument wird eingerückt
        $document->formatOutput = true;
        // das Wurzelelement und seine Nachkommen
        $document->append(self::element($document, $root, $data));
        // der XML-Text des Dokuments
        return $document->saveXml();
    }

    // gibt das XML-Element [<$name>$value</$name>] zurück
    private static function element(\Dom\XMLDocument $document, string $name, mixed $value): \Dom\Element
    {
        $element = $document->createElement($name);
        if (is_array($value)) {
            // ein Array: jedes Element des Arrays wird zu einem Kindelement (rekursiver Aufruf)
            foreach ($value as $key => $subValue) {
                // die Elemente einer Liste (Schlüssel 0, 1, 2...) heißen [item]
                $element->append(self::element($document, is_int($key) ? "item" : $key, $subValue));
            }
        } else {
            // ein einfacher Wert wird zum Text des Elements (die Zeichen <, >, & werden von DOM codiert)
            $element->textContent = match (true) {
                is_bool($value) => $value ? "true" : "false",
                default => (string) $value,
            };
        }
        return $element;
    }
}

    Anmerkungen

    • Zeile 9: Wie die Klasse [Utilities] in Version 5 hat diese Klasse nur statische Methoden. Sie ist [final], und ihr Konstruktor ist privat: Sie kann weder abgeleitet noch instanziiert werden;
    • Zeile 18: Die statische Methode [arrayToXml] gibt das XML-Dokument aus dem als Parameter übergebenen Array [$data] zurück. Der zweite Parameter ist der Name des Wurzelelements des Dokuments;
    • Zeile 21: Wir verwenden die neue DOM-API aus PHP 8.4, die im vorherigen Kapitel vorgestellt wurde. Die statische Methode [createEmpty] erzeugt ein leeres XML-Dokument. Das PHP-7-Skript verwendete [SimpleXML], das ebenfalls ein Dokument erzeugen kann, jedoch nicht so gut: Die Sonderzeichen im Text mussten Sie selbst mit der Funktion [htmlspecialchars] codieren;
    • Zeile 23: Das entstehende Dokument wird eingerückt, was es besser lesbar macht;
    • Zeile 25: Das Wurzelelement des Dokuments, das mit der Methode [element] erzeugt wird, wird dem Dokument hinzugefügt;
    • Zeile 27: Die Methode [saveXml] liefert den XML-Text des Dokuments;
    • Zeile 31: Die private Methode [element] gibt das XML-Element mit dem Namen [$name] zurück, das den Wert [$value] darstellt;
    • Zeile 33: Die Methode [createElement] des Dokuments erzeugt das Element;
    • Zeilen 34–38: Ist der Wert ein Array, wird jedes seiner Elemente zu einem Kindelement, das durch einen rekursiven Aufruf der Methode [element] erzeugt wird. Die Schlüssel des Arrays werden zu den Namen der Kindelemente. Die Schlüssel einer Liste sind die ganzen Zahlen 0, 1, 2 ..., die keine gültigen XML-Elementnamen sind: Diese Elemente heißen deshalb [item]. Das PHP-7-Skript nannte sie [i0], [i1], [i2] ...;
    • Zeilen 40–45: Andernfalls wird der Wert zum Text des Elements und seiner Eigenschaft [textContent] zugewiesen. Die Zeichen [<], [>], und [&] im Text werden von DOM codiert ([&lt;], [&gt;], [&amp;]). Boolesche Werte werden als [true] und [false] geschrieben; andere Werte werden in Strings umgewandelt. Der Ausdruck [match (true)] wählt den ersten Zweig, dessen Bedingung wahr ist.

// Senden der HTTP-Antwort an den Client
// $result: das zu sendende Array in Form des XML-Dokuments <response>...</response>
// $statusCode: der HTTP-Status der Antwort
// $headers: der Antwort hinzuzufügende HTTP-Header
// $logger: das Log der Anwendung (null, wenn es nicht erstellt werden konnte)
// $redis: der Redis-Client (null, wenn er noch nicht erstellt wurde)
function sendResponse(
    array $result,
    int $statusCode,
    array $headers = [],
    ?Logger $logger = null,
    ?RedisClient $redis = null
): void {
    // die XML-Antwort
    $response = new Response(XmlUtilities::arrayToXml($result, "response"), $statusCode, $headers);
    $response->headers->set("Content-Type", "application/xml; charset=utf-8");
    // Senden
    $response->send();
    // Log in JSON, kompakter als XML
    $logger?->write(json_encode(
        ["response" => $result],
        JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_PRESERVE_ZERO_FRACTION
    ));
    // Schließen der Verbindung zum Redis-Server
    $redis?->disconnect();
}

    Anmerkungen

    • Zeile 63: Die Antwort des Servers wird gelesen. Es ist ein XML-Dokument [<response>…</response>];
    • Zeile 72: Die Funktion [simplexml_load_string] parst das empfangene XML-Dokument und gibt ein Objekt [SimpleXMLElement] zurück, das sein Wurzelelement darstellt, oder [false] , wenn das Dokument kein gültiges XML-Dokument ist. Standardmäßig meldet die Bibliothek [libxml], die von [SimpleXML] verwendet wird, Dokumentfehler auch als PHP-Warnungen: Die Optionen [LIBXML_NOERROR] und [LIBXML_NOWARNING] unterdrücken sie. Sie werden über das benannte Argument [options] übergeben, wodurch man den Parameter [class_name] , der in der Signatur der Funktion davor steht, nicht schreiben muss;
    • Zeile 73: Die Methode [getName] gibt den Namen des Wurzelelements zurück, der [response] lauten muss;
    • Zeilen 77–85: Im Fehlerfall ist die Meldung der Ausnahme der JSON-String der Serverantwort statt des empfangenen XML-Strings, weil der JSON-String kompakter ist. Um das assoziative Array der XML-Antwort zu erhalten, verwenden wir einen klassischen Trick: Die Funktion [json_encode] kann ein Objekt [SimpleXMLElement] in JSON umwandeln, und [json_decode] wandelt dieses JSON anschließend in ein Array um. Die Meldung der Ausnahme hat so dasselbe Format wie in den vorherigen Versionen;
    • Zeilen 97–103: Das Ergebnis-Array wird zurückgegeben. Auf die Kindelemente des Elements [response] wird wie auf Eigenschaften des Objekts [$xml] zugegriffen ([$xml->tax]). In einem XML-Dokument sind alle Werte Text: Anders als JSON unterscheidet XML nicht zwischen ganzen Zahlen, reellen Zahlen und Zeichenketten. Jeder Wert wird daher in den von der Schicht [business] erwarteten Typ umgewandelt, und zwar mit den Operatoren [(int)] und [(float)] . Der PHP-7-Client gab die Werte als Strings zurück.
