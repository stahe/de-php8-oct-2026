    8. Praktische Übung – Version 3

    Wir greifen die zuvor behandelte Übung (Versionen 1 und 2) wieder auf und lösen sie mit PHP-Code, der Klassen verwendet. Dabei wenden wir an, was wir in den vorherigen drei Kapiteln gelernt haben:

    • eine (unveränderliche) Klasse [readonly] zur Darstellung der Daten der Steuerverwaltung;
    • eine Schnittstelle, eine abstrakte Klasse, die sie teilweise implementiert, und eine abgeleitete Klasse, die sie vervollständigt;
    • ein einziger Ausnahmetyp, [TaxException], um alle Anwendungsfehler zu melden;
    • das Attribut [#[\Override]] bei allen Methoden, die eine Schnittstellenmethode implementieren oder eine Methode der Elternklasse überschreiben.

    Kommentare

    • Zeile 6: Die Klasse [TaxException] befindet sich im Namespace [Application]. Alle Klassen und Schnittstellen der Steuerberechnungsanwendung liegen in diesem Namespace;
    • Zeile 9: Die Klasse [TaxException] erweitert die vordefinierte PHP-Klasse [RuntimeException]. Wie wir im Kapitel über Ausnahmen gesehen haben, wird eine Ausnahme in erster Linie durch ihren Typ definiert: Der Typ ermöglicht es, sie mit einer Klausel [catch (TaxException $ex)] abzufangen;
    • Zeilen 11–12: Im PHP-7-Kurs wurde ein Konstruktor [__construct(string $message, int $code = 0)] definiert, der lediglich den Konstruktor der Elternklasse aufrief. Das ist unnötig: Die Klasse erbt den Konstruktor von [RuntimeException], der eine Meldung, einen Fehlercode und eine eventuelle vorherige Ausnahme akzeptiert. Diesen letzten Parameter verwenden wir, um eine Low-Level-Ausnahme (zum Beispiel eine [JsonException], ) in einer [TaxException] zu kapseln.

    <?php

declare(strict_types=1);

// Namespace
namespace Application;

// die Daten der Steuerverwaltung: ein unveränderliches Objekt
final readonly class TaxAdminData
{
    // die Namen der in den Daten erwarteten Arrays und Konstanten
    private const array ARRAYS = ["limits", "coeffR", "coeffN"];
    private const array CONSTANTS = [
        "halfShareQfCeiling",
        "singleIncomeCeilingForReduction",
        "coupleIncomeCeilingForReduction",
        "halfShareReductionValue",
        "singleDiscountCeiling",
        "coupleDiscountCeiling",
        "coupleTaxCeilingForDiscount",
        "singleTaxCeilingForDiscount",
        "tenPercentAllowanceMax",
        "tenPercentAllowanceMin",
    ];

    // privater Konstruktor: man muss über die [from...]-Methoden gehen
    private function __construct(
        // Steuerstufen
        public array $limits,
        public array $coeffR,
        public array $coeffN,
        // Konstanten der Steuerberechnung
        public float $halfShareQfCeiling,
        public float $singleIncomeCeilingForReduction,
        public float $coupleIncomeCeilingForReduction,
        public float $halfShareReductionValue,
        public float $singleDiscountCeiling,
        public float $coupleDiscountCeiling,
        public float $coupleTaxCeilingForDiscount,
        public float $singleTaxCeilingForDiscount,
        public float $tenPercentAllowanceMax,
        public float $tenPercentAllowanceMin,
    ) {
    }

    // Erzeugung aus einer JSON-Datei
    public static function fromJsonFile(string $taxAdminDataFilename): self
    {
        // wir rufen den Inhalt der Steuerdatendatei ab
        $fileContents = is_readable($taxAdminDataFilename) ? file_get_contents($taxAdminDataFilename) : false;
        // Fehler?
        if ($fileContents === false) {
            throw new TaxException("The data file [$taxAdminDataFilename] does not exist", 1);
        }
        // wir dekodieren das JSON in ein assoziatives Array
        try {
            $data = json_decode($fileContents, true, flags: JSON_THROW_ON_ERROR);
        } catch (\JsonException $ex) {
            throw new TaxException("The JSON data file [$taxAdminDataFilename] could not be processed correctly", 2, $ex);
        }
        // das JSON muss ein Objekt {...} sein
        if (!is_array($data)) {
            throw new TaxException("The JSON data file [$taxAdminDataFilename] does not contain a JSON object", 3);
        }
        // Aufbau des Objekts aus dem assoziativen Array
        return self::fromArray($data);
    }

    // Erzeugung aus einem assoziativen Array [name => value]
    public static function fromArray(array $data): self
    {
        // die vorhandenen Schlüssel müssen genau die erwarteten sein
        $expected = [...self::ARRAYS, ...self::CONSTANTS];
        $missing = array_first(array_diff($expected, array_keys($data)));
        if ($missing !== null) {
            throw new TaxException("The attribute [$missing] of [TaxAdminData] has not been initialized", 4);
        }
        $unknown = array_first(array_diff(array_keys($data), $expected));
        if ($unknown !== null) {
            throw new TaxException("The attribute [$unknown] does not exist in [TaxAdminData]", 5);
        }
        // wir prüfen und konvertieren jeden Wert
        $values = [];
        foreach (self::ARRAYS as $key) {
            // ein nicht leeres Array von reellen Zahlen >= 0
            if (!is_array($data[$key]) || !array_is_list($data[$key]) || count($data[$key]) === 0) {
                throw new TaxException("The value of attribute [$key] is invalid", 6);
            }
            $values[$key] = array_map(fn(mixed $value): float => self::check($key, $value), $data[$key]);
        }
        // die drei Arrays müssen dieselbe Größe haben
        $size = count($values["limits"]);
        if (count($values["coeffR"]) !== $size || count($values["coeffN"]) !== $size) {
            throw new TaxException("The arrays [limits, coeffR, coeffN] do not have the same size", 7);
        }
        foreach (self::CONSTANTS as $key) {
            // eine reelle Zahl >= 0
            $values[$key] = self::check($key, $data[$key]);
        }
        // Aufbau des Objekts: die Schlüssel des Arrays werden zu benannten Argumenten
        return new self(...$values);
    }

    // prüft, ob ein Wert eine positive oder null reelle Zahl ist, und gibt ihn als [float] zurück
    private static function check(string $key, mixed $value): float
    {
        // wir akzeptieren 1551, 1551.78, "1551", aber nicht "xx", true, null, -3...
        if ((is_int($value) || is_float($value) || (is_string($value) && is_numeric($value)))
            && (float) $value >= 0) {
            return (float) $value;
        }
        throw new TaxException("The value of attribute [$key] is invalid", 6);
    }

    // JSON-String des Objekts
    public function __toString(): string
    {
        return json_encode(get_object_vars($this), JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR);
    }
}

    Kommentare

    • Zeile 9: Die Klasse ist [readonly]: Alle ihre Attribute sind schreibgeschützt. Einmal erzeugt, kann ein Objekt [TaxAdminData] nicht mehr verändert werden: Es kann gefahrlos von allen Teilen der Anwendung gemeinsam genutzt werden. Sie ist außerdem [final]: Von ihr kann nicht abgeleitet werden;
    • Zeilen 12–24: Zwei private Klassenkonstanten listen die Namen der in den Daten erwarteten Attribute auf. Ab PHP 8.3 kann eine Klassenkonstante typisiert sein (hier [array]);
    • Zeilen 27–43: Der Konstruktor verwendet Parameter-Promotion: Jeder Parameter wird zu einem öffentlichen Attribut mit demselben Namen und Typ. Die Attribute haben dieselben Namen wie die Schlüssel in der JSON-Datei. Das ist ein wichtiger Punkt, der das Schreiben des Codes erheblich vereinfacht, wie wir sehen werden. Die Steuerstufen sind Arrays ([array]), die Berechnungskonstanten reelle Zahlen ([float]). In PHP 7 konnten Attribute nicht typisiert werden (wie im PHP-7-Kurs angemerkt); ab PHP 7.4 können sie es;
    • Zeile 27: Der Konstruktor ist private; [new TaxAdminData(...)] kann außerhalb der Klasse nicht geschrieben werden. Ein Objekt [TaxAdminData] lässt sich nur über die statischen Methoden [fromJsonFile] und [fromArray] erhalten, die die Gültigkeit der Daten prüfen. So ist sichergestellt, dass jedes Objekt [TaxAdminData] gültige Daten enthält. In PHP kann eine Klasse nur einen Konstruktor haben. Statische Methoden, die ein Objekt konstruieren – manchmal „benannte Konstruktoren“ genannt –, ermöglichen mehrere Arten, ein Objekt zu konstruieren. Der PHP-7-Kurs verwendete Instanzmethoden [setFromJsonFile] , die auf einem leeren Objekt aufgerufen wurden: [(new TaxAdminData())->setFromJsonFile(...)]. Bei einem unveränderlichen Objekt ist das unmöglich;
    • Zeilen 47–67: Die Methode [fromJsonFile] konstruiert ein Objekt [TaxAdminData] aus der JSON-Datei, deren Name ihr übergeben wird. Ihr Rückgabetyp [self], bezeichnet die Klasse selbst;
    • Zeilen 50–53: Der Inhalt der Datei wird gelesen. Ist das nicht möglich, wird eine Ausnahme [TaxException] ausgelöst. Diese Ausnahme wird bis zum Hauptskript weitergereicht;
    • Zeilen 56–60: Der Inhalt der Datei, JSON, wird dekodiert. Mit der Option [JSON_THROW_ON_ERROR] (PHP 7.3) löst die Funktion [json_decode] bei ungültigem JSON eine Ausnahme [JsonException] aus, anstatt stillschweigend [null] zurückzugeben. Beachten Sie das benannte Argument [flags:], mit dem man vermeidet, dem dritten Parameter [depth] von [json_decode] einen Wert zuweisen zu müssen. Die Ausnahme [JsonException] wird in einer [TaxException] gekapselt: Der aufrufende Code muss nur einen Ausnahmetyp behandeln, kann aber die ursprüngliche Ursache mit [$ex->getPrevious()] ermitteln;
    • Zeilen 62–64: Eine Datei, die zum Beispiel nur die Zahl 12 enthält, ist gültiges JSON; man muss prüfen, dass tatsächlich ein Array erhalten wurde;
    • Zeile 66: Die restliche Arbeit wird an die Methode [fromArray] delegiert. Diese Methode ist öffentlich: Sie kann in einer künftigen Version verwendet werden, in der die Daten der Steuerverwaltung aus einer Datenbank stammen;
    • Zeilen 73–81: Wir prüfen, dass die Schlüssel des Arrays [$data] genau den erwarteten Namen entsprechen. [[...self::ARRAYS, ...self::CONSTANTS]] erzeugt ein Array, das die Elemente beider Arrays enthält. Die Funktion [array_diff] liefert die Elemente des ersten Arrays, die im zweiten fehlen, und die Funktion [array_first] (PHP 8.5) liefert das erste Element eines Arrays oder [null] , wenn das Array leer ist. So wird erst ein fehlender, dann ein unbekannter Schlüssel erkannt. Das ist der häufigste Fehler: ein Tippfehler in einem Attributnamen in der Datei [taxadmindata.json]. Im PHP-7-Kurs erzeugte die Schleife [$this->$key = $value] stillschweigend ein dynamisches Attribut mit dem falschen Namen. Seit PHP 8.2 ist das Erzeugen dynamischer Attribute veraltet, und in einer Klasse [readonly] ist es verboten;
    • Zeilen 84–90: Jedes der drei Arrays muss eine nicht leere Liste sein (Funktion [array_is_list], PHP 8.1), deren Elemente alle positive reelle Zahlen oder null sind. Die Funktion [array_map] wendet die Methode [check] auf jedes Element an;
    • Zeilen 92–95: Die drei Arrays der Steuerstufen müssen gleich groß sein;
    • Zeilen 96–99: Jede der Berechnungskonstanten muss eine positive reelle Zahl oder null sein;
    • Zeile 101: Das Array [$values] verwendet die Namen der Konstruktorparameter als Schlüssel. Der Operator [...], auf ein Array mit String-Schlüsseln angewendet, wandelt jedes Element in ein benanntes Argument um (PHP 8.1): Diese Zeile entspricht [new self(limits: $values["limits"], coeffR: $values["coeffR"], ...)]. Hier vereinfacht die Wahl identischer Namen für die JSON-Schlüssel und die Klassenattribute den Code;
    • Zeilen 105–113: Die Methode [check] prüft, ob ein Wert [$value] unbekannten Typs ([mixed]) eine positive Zahl oder null ist. Je nach Inhalt der JSON-Datei kann der gelesene Wert eine ganze Zahl (1551), eine Gleitkommazahl (1551.78), eine in eine Zahl umwandelbare Zeichenkette ("1551"), eine nicht umwandelbare Zeichenkette ("xx"), ein Boolescher Wert ... sein. Die Funktion [is_numeric] liefert [true] für eine Zeichenkette, die eine Zahl darstellt. Der PHP-7-Kurs führte diese Prüfung mit einem regulären Ausdruck durch und gab ein Objekt [stdClass] zurück, das anzeigte, ob ein Fehler aufgetreten war. Hier löst ein Fehler eine Ausnahme aus, und die Methode gibt einfach die Zahl als [float] zurück;
    • Zeile 116: Die Methode [__toString] liefert die JSON-Zeichenkette mit den Attributen des Objekts. Die Funktion [get_object_vars] liefert ein assoziatives Array [Attributname => Wert].

    8.3.1. Warum gibt es keine Getter und Setter mehr?

    Der PHP-7-Kurs deklarierte die Attribute als privat und schrieb für jedes einen Getter und einen Setter (26 Methoden), die von der IDE NetBeans automatisch erzeugt wurden. Die Setter waren „fluent“: Sie gaben das Objekt [$this] zurück, was verkettete Aufrufe wie [$data->setLimits($limits)->setCoeffR($coeffR)] ermöglichte.

    Mit PHP 8 ist dieser Code nicht mehr nötig:

    • Die Getter dienten dazu, private Attribute zu lesen. Die Attribute [readonly] können gefahrlos öffentlich gemacht werden, da sie nicht verändert werden können: Wir schreiben [$taxAdminData->halfShareQfCeiling] statt [$taxAdminData->getHalfShareQfCeiling()];
    • Die Setter dienten dazu, das Objekt zu initialisieren, und erlaubten die Validierung von Werten. Ein unveränderliches Objekt wird einmalig durch seinen Konstruktor initialisiert, und die Validierung übernehmen die Methoden [fromJsonFile] und [fromArray];
    • Typisierte Attribute garantieren den Typ der Werte. Der PHP-7-Kurs hatte festgestellt, dass die Anweisung [$this->halfShareQfCeiling = 'abcd'] möglich war: Mit Attributen vom Typ [float] und [declare(strict_types=1)] führt sie zu einem Fehler [TypeError].

    public function calculateTax(string $married, int $children, int $salary): array
    {
        // $married: ja, nein
        // $children: Anzahl der Kinder
        // $salary: Jahresgehalt
        // $this->taxAdminData: Daten der Steuerverwaltung
        //
        // wir rufen die Daten der Steuerverwaltung ab, falls dies noch nicht geschehen ist

        $tax1 = $result1["tax"];
        // Berechnung der Steuer ohne die Kinder

            $result2 = $this->calculateTax2($married, 0, $salary);
            $tax2 = $result2["tax"];
            // Anwendung der Obergrenze des Familienquotienten
            $halfShareCeiling = $this->taxAdminData->halfShareQfCeiling;
            if ($children < 3) {
                // halfShareQfCeiling Euro für die ersten 2 Kinder
                $tax2 = $tax2 - $children * $halfShareCeiling;
            } else {
                // halfShareQfCeiling Euro für die ersten 2 Kinder, doppelt für die weiteren
                $tax2 = $tax2 - 2 * $halfShareCeiling - ($children - 2) * 2 * $halfShareCeiling;
            }
        } else {
            $tax2 = $tax1;
            $result2 = $result1;
        }
        // wir nehmen die höhere Steuer mit dem dazugehörigen Satz und Zuschlag
        if ($tax1 > $tax2) {
            $tax = $tax1;
            $rate = $result1["rate"];
            $surcharge = $result1["surcharge"];
        } else {
            $surcharge = $tax2 - $tax1 + $result2["surcharge"];
            $tax = $tax2;
            $rate = $result2["rate"];
        }
        // Berechnung einer eventuellen Ermäßigung
        $discount = $this->getDiscount($married, $salary, $tax);
        $tax -= $discount;
        // Berechnung einer eventuellen Steuerminderung
        $reduction = $this->getReduction($married, $salary, $children, $tax);
        $tax -= $reduction;
        // Ergebnis
        return [
            "tax" => (int) floor($tax),
            "surcharge" => (int) $surcharge,
            "discount" => (int) $discount,
            "reduction" => (int) $reduction,
            "rate" => $rate,

        // --------------------------------------------------------------------------
    private function calculateTax2(string $married, int $children, float $salary): array
    {
        // Anzahl der Anteile
        $nbShares = match ($married) {
            "yes" => $children / 2 + 2,
            "no" => $children / 2 + 1,
        };
        // 1 Anteil pro Kind ab dem 3.
        if ($children >= 3) {
            // ein weiterer halber Anteil für jedes Kind ab dem 3.
            $nbShares += 0.5 * ($children - 2);
        }
        // zu versteuerndes Einkommen
        $taxableIncome = $this->getTaxableIncome($salary);
        // Zuschlag
        $surcharge = floor($taxableIncome - 0.9 * $salary);
        // wegen Rundungsproblemen
        if ($surcharge < 0) {
            $surcharge = 0;
        }
        // Familienquotient
        $quotient = $taxableIncome / $nbShares;
        // die Steuerstufen (Kopien der Arrays des Objekts)
        $limits = $this->taxAdminData->limits;
        $coeffR = $this->taxAdminData->coeffR;
        $coeffN = $this->taxAdminData->coeffN;
        // wird ans Ende des Arrays limits gesetzt, um die folgende Schleife zu stoppen
        $limits[count($limits) - 1] = $quotient;
        // Berechnung der Steuer
        $i = 0;
        while ($quotient > $limits[$i]) {
            $i++;
        }
        // jetzt können wir die Steuer berechnen
        $tax = floor($taxableIncome * $coeffR[$i] - $nbShares * $coeffN[$i]);
        // Ergebnis
        return ["tax" => $tax, "surcharge" => $surcharge, "rate" => $coeffR[$i]];
    }

    // taxableIncome=annualSalary-allowance
    // der Freibetrag hat ein Minimum und ein Maximum
    private function getTaxableIncome(float $salary): float
    {
        // Freibetrag von 10 % des Gehalts, begrenzt durch ein Minimum und ein Maximum
        $allowance = 0.1 * $salary;
        $allowance = min($allowance, $this->taxAdminData->tenPercentAllowanceMax);
        $allowance = max($allowance, $this->taxAdminData->tenPercentAllowanceMin);
        // zu versteuerndes Einkommen
        $taxableIncome = $salary - $allowance;
        // Ergebnis
        return floor($taxableIncome);
    }

    // berechnet eine eventuelle Ermäßigung
    private function getDiscount(string $married, float $salary, float $taxes): float
    {
        // zu Beginn eine Ermäßigung von null
        $discount = 0;
        // maximaler Steuerbetrag, um die Ermäßigung zu erhalten
        $taxCeilingForDiscount = $married === "yes"
            ? $this->taxAdminData->coupleTaxCeilingForDiscount
            : $this->taxAdminData->singleTaxCeilingForDiscount;
        if ($taxes < $taxCeilingForDiscount) {
            // maximaler Betrag der Ermäßigung
            $discountCeiling = $married === "yes"
                ? $this->taxAdminData->coupleDiscountCeiling
                : $this->taxAdminData->singleDiscountCeiling;
            // theoretische Ermäßigung
            $discount = $discountCeiling - 0.75 * $taxes;
            // die Ermäßigung darf den Steuerbetrag nicht übersteigen
            if ($discount > $taxes) {
                $discount = $taxes;
            }
            // keine Ermäßigung < 0
            if ($discount < 0) {
                $discount = 0;
            }
        }
        // Ergebnis
        return ceil($discount);
    }

    // berechnet eine eventuelle Minderung
    private function getReduction(string $married, float $salary, int $children, float $taxes): float
    {
        // die Einkommensgrenze, um Anspruch auf die Minderung von 20 % zu haben
        $incomeCeilingForReduction = $married === "yes"
            ? $this->taxAdminData->coupleIncomeCeilingForReduction
            : $this->taxAdminData->singleIncomeCeilingForReduction;
        $incomeCeilingForReduction += $children * $this->taxAdminData->halfShareReductionValue;
        if ($children > 2) {
            $incomeCeilingForReduction += ($children - 2) * $this->taxAdminData->halfShareReductionValue;
        }
        // zu versteuerndes Einkommen
        $taxableIncome = $this->getTaxableIncome($salary);
        // Minderung
        $reduction = 0;
        if ($taxableIncome < $incomeCeilingForReduction) {
            // Minderung von 20 %
            $reduction = 0.2 * $taxes;
        }
        // Ergebnis
        return ceil($reduction);
    }

        // Steuerberechnung im Batch-Modus
    // --------------------------------------------------------------------------
    #[\Override]
    public function executeBatchTaxes(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void
    {
        // die drei Dateien sind noch nicht geöffnet
        $errors = $results = $data = false;
        // sobald Dateien verarbeitet werden, können einige Fehler auftreten
        try {
            // Öffnen der Fehlerdatei
            $errors = fopen($errorsFileName, "w");
            if ($errors === false) {
                throw new TaxException("Unable to create the errors file [$errorsFileName]", 10);
            }
            // Öffnen der Ergebnisdatei
            $results = fopen($resultsFileName, "w");
            if ($results === false) {
                throw new TaxException("Unable to create the results file [$resultsFileName]", 11);
            }
            // Öffnen der Datei mit den Steuerpflichtigendaten
            $data = is_readable($taxPayersFileName) ? fopen($taxPayersFileName, "r") : false;
            if ($data === false) {
                throw new TaxException("Unable to open the taxpayers' declarations [$taxPayersFileName] for reading", 12);
            }
            // wir verarbeiten die aktuelle Zeile der Datei mit den Steuerpflichtigendaten
            // die die Form Familienstand, Anzahl der Kinder, Jahresgehalt hat
            $num = 0;         // Nr. der aktuellen Zeile
            $nbErrors = 0;    // Anzahl der aufgetretenen Fehler
            while (($line = fgets($data, 100)) !== false) {
                // eine Zeile mehr
                $num++;
                // wir entfernen ein eventuelles Zeilenende-Zeichen
                $line = Utilities::cutNewLineChar($line);
                // wir ignorieren die leeren Zeilen
                if (trim($line) === "") {
                    continue;
                }
                // die Zeile muss 3 Felder haben: married,children,salary
                $fields = array_map(trim(...), explode(",", $line));
                $error = count($fields) !== 3;
                if (!$error) {
                    [$married, $children, $salary] = $fields;
                    // der Familienstand muss yes oder no sein
                    $married = strtolower($married);
                    // die Anzahl der Kinder und das Gehalt müssen positive oder null ganze Zahlen sein
                    $error = !in_array($married, ["yes", "no"], true)
                        || !preg_match('/^\d+$/', $children)
                        || !preg_match('/^\d+$/', $salary);
                }
                // Fehler?
                if ($error) {
                    fputs($errors, "line [$num] of the file [$taxPayersFileName] is incorrect\n");
                    $nbErrors++;
                    continue;
                }
                // wir berechnen die Steuer
                $result = $this->calculateTax($married, (int) $children, (int) $salary);
                // wir schreiben das Ergebnis in die Ergebnisdatei
                $result = ["married" => $married, "children" => (int) $children, "salary" => (int) $salary] + $result;
                fputs($results, json_encode($result, JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR) . "\n");
            }
            // Fehler?
            if ($nbErrors > 0) {
                throw new TaxException("There were $nbErrors incorrect line(s): see the file [$errorsFileName]", 15);
            }
        } finally {
            // wir schließen die Dateien, die geöffnet wurden
            foreach ([$data, $results, $errors] as $file) {
                if ($file !== false) {
                    fclose($file);
                }
            }
        }
    }

    • Zeile 214: Die statische Methode [Utilities::cutNewLineChar] wird verwendet, um eventuelle Zeilenendzeichen zu entfernen;
    • Zeilen 216–218: Leere Zeilen (zum Beispiel am Ende der Datei) werden ignoriert;
    • Zeile 220: Die Zeile wird am Komma aufgeteilt, und die Leerzeichen um jedes Feld werden entfernt. [trim(...)] ist die Syntax für „First-Class Callables“ (PHP 8.1): Sie verweist auf die Funktion [trim] selbst, ohne sie aufzurufen;
    • Zeile 221: Die Zeile muss genau drei Felder haben. Der PHP-7-Kurs schrieb direkt [list($married, $children, $salary) = explode(",", $line)]: Bei einer Zeile mit nur zwei Feldern gibt PHP 8 die Warnung „Undefined array key 2“ aus;
    • Zeilen 227–229: Die Gültigkeit der drei Elemente wird geprüft: Der Familienstand muss „yes“ oder „no“ sein, und die Anzahl der Kinder und das Gehalt müssen positive ganze Zahlen oder null sein (eine Ziffernfolge, regulärer Ausdruck [/^\d+$/]). Der dritte Parameter [true] von [in_array] erzwingt einen strikten Vergleich [===];
    • Zeilen 232–236: Ist die Zeile ungültig, wird keine Ausnahme ausgelöst; stattdessen wird eine Fehlermeldung in die Textdatei [$errors] geschrieben, und das Programm geht zur nächsten Zeile über;
    • Zeile 238: Ist die gelesene Zeile gültig, wird die Steuer berechnet. Das Ergebnis wird als assoziatives Array [tax, surcharge, discount, reduction, rate] zurückgegeben;
    • Zeile 240: Die Schlüssel [married, children, salary] werden am Anfang des Ergebnisses hinzugefügt;
    • Zeile 241: Das Ergebnis wird in Form seiner JSON-Zeichenkette in die Textdatei [$results] geschrieben. Die Option [JSON_THROW_ON_ERROR] bewirkt, dass die Funktion [json_encode] eine Ausnahme [JsonException] auslöst, anstatt [false] zurückzugeben, wenn die Kodierung fehlschlägt;
    • Zeilen 244–246: Nach der Verarbeitung der Datei [$data] wird die Anzahl der fehlerhaften Zeilen geprüft. Gibt es mindestens eine, wird eine Ausnahme ausgelöst;
    • Zeilen 247–254: Unabhängig davon, wie die Ausführung der Methode endet (normal oder durch eine Ausnahme), wird die Klausel [finally] ausgeführt: Alle geöffneten Dateien werden geschlossen. Der PHP-7-Kurs verwendete eine Struktur [try / catch / finally] , deren Klausel [catch] die Ausnahme lediglich erneut auslöste. Das ist unnötig: Eine Struktur [try / finally] ohne [catch] lässt die Ausnahme weiterlaufen, nachdem die Klausel [finally] ausgeführt wurde. Außerdem schloss der PHP-7-Kurs die drei Dateien, ohne zu prüfen, ob sie geöffnet worden waren: In PHP 8 verursacht [fclose(false)] einen Fehler [TypeError].

    <?php

declare(strict_types=1);

// Namespace
namespace Application;

// eine Klasse, die die Daten der Steuerverwaltung aus einer JSON-Datei bezieht
class TaxWithTaxAdminDataInJsonFile extends AbstractBaseTax
{
    // die Daten der Steuerverwaltung
    private readonly TaxAdminData $taxAdminData;

    // der Konstruktor
    public function __construct(string $jsonFileName)
    {
        // wir initialisieren $this->taxAdminData aus der JSON-Datei
        // kann eine TaxException werfen
        $this->taxAdminData = TaxAdminData::fromJsonFile($jsonFileName);
    }

    // gibt die zur Steuerberechnung verwendeten Daten zurück
    #[\Override]
    public function getTaxAdminData(): TaxAdminData
    {
        return $this->taxAdminData;
    }
}

    Kommentare

    • Zeile 9: Die Klasse [TaxWithTaxAdminDataInJsonFile] erweitert die abstrakte Klasse [AbstractBaseTax]. Sie muss die Methode [getTaxAdminData] definieren, die ihre Elternklasse nicht definiert hat;
    • Zeile 12: Das Attribut [$taxAdminData] enthält die Daten der Steuerbehörde. Es ist schreibgeschützt: Es wird einmalig vom Konstruktor initialisiert. Beachten Sie, dass auch die Elternklasse ein privates Attribut [$taxAdminData] hat: Die beiden Attribute sind verschieden, da ein privates Attribut nur innerhalb der Klasse sichtbar ist, die es deklariert;
    • Zeilen 15–20: Der Konstruktor erhält als einzigen Parameter den Namen der JSON-Datei mit den Steuerdaten;
    • Zeile 19: Es wird ein Objekt vom Typ [TaxAdminData] aus der JSON-Datei erzeugt. Dieser Vorgang kann eine Ausnahme vom Typ [TaxException] auslösen. Diese Ausnahme wird bis zum Hauptskript [main.php] weitergereicht;
    • Zeilen 23–27: Für die Methode [getTaxAdminData], die die Elternklasse nicht definiert hatte, wird ein Rumpf bereitgestellt. Hier genügt es, sicherzustellen, dass das Attribut [$this->taxAdminData] vom Konstruktor initialisiert wird.

    8.10. Fazit

    Version 3 bietet dieselbe Funktionalität wie Version 2, ist aber besser für die Fehlerbehandlung gerüstet: unvollständige oder fehlerhafte Steuerdaten, fehlerhafte Zeilen in der Datei der Steuerpflichtigen oder fehlende Dateien. Jeder Fehler wird durch eine Ausnahme [TaxException] mit einer Meldung und einem spezifischen Code angezeigt.

    Die Klasse [AbstractBaseTax] vereint jedoch zwei Arten von Code: einerseits die Steuerberechnung, andererseits das Lesen und Schreiben von Dateien. In den folgenden Kapiteln werden wir sehen, wie sich diese beiden Aufgabenbereiche in verschiedene Schichten trennen lassen.
