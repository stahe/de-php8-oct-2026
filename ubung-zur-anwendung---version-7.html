    In dieser Konfiguration gilt:

    • Zeilen 2–6: die Pfade zu allen JSON-Dateien der Anwendung. Die verwendete Datenbank ist PostgreSQL;
    • Zeilen 7–20: die Pfade zu allen PHP-Dateien der Anwendung in der Form [key => path]. Es sind die Dateien aus Version 5;
    • Zeilen 21–32: die Abhängigkeiten für die Steuerberechnung in Form einer Liste von Schlüsseln aus dem Dictionary [dependencies];
    • Zeilen 33–40: die Abhängigkeiten für die Übertragung der Daten aus der JSON-Datei [taxadmindata.json] in die Datenbank, im selben Format.

    Alle Pfade beziehen sich auf den Ordner [version-07]. Der PHP-7-Kurs fügte dieser Datei einen Schlüssel namens [rootDirectory] hinzu, der den absoluten Pfad zum Versionsordner auf dem Rechner des Autors angab (["C:/Data/st-2019/dev/php7/poly/scripts-console/impots/version-07"]): Dieser musste auf jedem neuen Rechner angepasst werden. Die Skripte berechnen diesen Ordnerpfad nun selbst anhand der Konstante [__DIR__]. Der Ordner [php8-oct-2026] kann daher an beliebiger Stelle liegen.

    Kommentare

    Der Code bleibt derselbe wie in Version 6. Der einzige Unterschied ist die Verwendung der Datei [config.json] anstelle der Konstanten:

    • Zeile 10: Das Wurzelverzeichnis von Version 7, auf das sich die Pfade in der Konfigurationsdatei beziehen. [__DIR__] ist der Ordner [Main] des Skripts; [__DIR__ . "/.."] ist dessen übergeordneter Ordner, [version-07];
    • Zeile 12: der Pfad zur Konfigurationsdatei;
    • Zeile 15: Die Funktion [file_get_contents] wandelt die Datei [config.json] in einen String um. Die Funktion [json_decode] erstellt daraus dann das assoziative Array [$config]. Der zweite Parameter [true] der Funktion [json_decode] legt fest, dass ein assoziatives Array statt eines Objekts gewünscht ist. Mit der Option [JSON_THROW_ON_ERROR] löst ein Syntaxfehler in der Datei eine Exception vom Typ [JsonException] aus. Wir versuchen hier nicht, Lesefehler der Konfigurationsdatei zu behandeln: Diese Datei gehört zur Anwendung, und ein Fehler auf dieser Ebene ist ein Programmierfehler, den PHP selbst meldet. Datenfehler (JSON-Datendateien, Datenbank) werden dagegen stets durch eine [TaxException] gemeldet;
    • Zeilen 18–20: Die vom Übertragungsskript benötigten Abhängigkeiten werden eingebunden:
      • [$config["dependencies4transfer"]] ist die Tabelle der Abhängigkeiten, die das Übertragungsskript benötigt. Sie ist eine Liste von Schlüsseln;
      • Die Pfade der einzubindenden Dateien finden sich im Dictionary [$config["dependencies"]] und werden mit dem Wurzelverzeichnis versehen. Der Schlüssel [TaxException] verweist zum Beispiel auf die Datei [version-07/../version-05/Entities/TaxException.php];
      • [require_once] (nicht [require] wie im PHP-7-Kurs) stellt sicher, dass eine Datei nicht zweimal geladen wird, was den schweren Fehler „Cannot redeclare class … (previously declared in …)“ verursachen würde;
    • Zeilen 23–24: die vollständigen Pfade zu den Datendateien. Der PHP-7-Kurs speicherte sie in Konstanten, die mit der Funktion [define] erzeugt wurden. Variablen genügen;
    • Zeile 31: Der Name der Datei, die die verwendete Datenbank beschreibt, wird angezeigt. In einem String in Anführungszeichen muss das Array-Element [$config["databaseFilename"]] in geschweifte Klammern gesetzt werden.

Im PHP-7-Kurs verwiesen sie auf PostgreSQL ([MainTransferAdminDataFromFile2PostgresSQLDatabase.php], [MainCalculateImpotsWithTaxAdminDataInPostgresDatabase.php]). Wenn Sie in dieser Datei ["Data/database-pgsql.json"] durch ["Data/database-mysql.json"] ersetzen, verwendet das Übertragungsskript die MySQL-Datenbank, ohne dass eine einzige Zeile PHP-Code geändert wird:

// strikte Einhaltung der deklarierten Typen der Funktionsparameter und -ergebnisse
declare(strict_types=1);

// Namespace der Tests
namespace Application\Tests;

// die getesteten Klassen
use Application\DaoTaxWithTaxAdminDataInDatabase;
use Application\DaoTransferAdminDataFromJsonFile2Database;
use Application\TaxAdminData;
// die PHPUnit-Klassen
use PHPUnit\Framework\Attributes\DataProvider;
use PHPUnit\Framework\TestCase;

final class DaoTest extends TestCase
{
    // der Wurzelordner der Version 7
    private const string ROOT_DIRECTORY = __DIR__ . "/..";
    // die Konfiguration der Anwendung
    private static array $config;

    // einmal vor dem ersten Test der Klasse ausgeführt
    #[\Override]
    public static function setUpBeforeClass(): void
    {
        // wir rufen die Konfiguration ab
        self::$config = json_decode(file_get_contents(self::ROOT_DIRECTORY . "/Data/config.json"), true, flags: JSON_THROW_ON_ERROR);
        // wir binden die Abhängigkeiten der Steuerberechnung und die der Datenübertragung ein
        $dependencies = array_unique([...self::$config["dependencies4calculate"], ...self::$config["dependencies4transfer"]]);
        foreach ($dependencies as $dependency) {
            require_once self::ROOT_DIRECTORY . "/" . self::$config["dependencies"][$dependency];
        }
    }

    // die beiden Datenbanken
    public static function databases(): array
    {
        // [Datei mit der Datenbankbeschreibung]
        return [
            "MySQL" => ["Data/database-mysql.json"],
            "PostgreSQL" => ["Data/database-pgsql.json"],
        ];
    }

    // die aus der Datenbank gelesenen Daten der Steuerverwaltung
    #[DataProvider("databases")]
    public function testTaxAdminData(string $databaseFilename): void
    {
        $dao = new DaoTaxWithTaxAdminDataInDatabase(self::ROOT_DIRECTORY . "/$databaseFilename");
        $taxAdminData = $dao->getTaxAdminData();
        // Berechnungskonstanten
        $this->assertSame(1551.0, $taxAdminData->halfShareQfCeiling);
        $this->assertSame(21037.0, $taxAdminData->singleIncomeCeilingForReduction);
        $this->assertSame(42074.0, $taxAdminData->coupleIncomeCeilingForReduction);
        $this->assertSame(3797.0, $taxAdminData->halfShareReductionValue);
        $this->assertSame(1196.0, $taxAdminData->singleDiscountCeiling);
        $this->assertSame(1970.0, $taxAdminData->coupleDiscountCeiling);
        $this->assertSame(1595.0, $taxAdminData->singleTaxCeilingForDiscount);
        $this->assertSame(2627.0, $taxAdminData->coupleTaxCeilingForDiscount);
        $this->assertSame(12502.0, $taxAdminData->tenPercentAllowanceMax);
        $this->assertSame(437.0, $taxAdminData->tenPercentAllowanceMin);
        // Steuerstufen
        $this->assertSame([9964.0, 27519.0, 73779.0, 156244.0, 0.0], $taxAdminData->limits);
        $this->assertSame([0.0, 0.14, 0.30, 0.41, 0.45], $taxAdminData->coeffR);
        $this->assertSame([0.0, 1394.96, 5798.0, 13913.69, 20163.45], $taxAdminData->coeffN);
    }

    // die Übertragung der JSON-Datei in die Datenbank, dann das erneute Lesen der Datenbank
    #[DataProvider("databases")]
    public function testTransfer(string $databaseFilename): void
    {
        // die JSON-Dateien
        $databaseFilename = self::ROOT_DIRECTORY . "/$databaseFilename";
        $taxAdminDataFilename = self::ROOT_DIRECTORY . "/" . self::$config["taxAdminDataFilename"];
        // Übertragung
        (new DaoTransferAdminDataFromJsonFile2Database($databaseFilename, $taxAdminDataFilename))->transferAdminData2Database();
        // erneutes Lesen der Datenbank durch eine Schicht [dao]
        $dao = new DaoTaxWithTaxAdminDataInDatabase($databaseFilename);
        // die Datenbank enthält die Daten der JSON-Datei
        $this->assertEquals(TaxAdminData::fromJsonFile($taxAdminDataFilename), $dao->getTaxAdminData());
    }
}

    Kommentare

    • Zeilen 10–12: Die getesteten Klassen werden importiert. Die Anweisung [use] lädt die Klassen nicht, sondern erlaubt lediglich, sie mit ihren Kurznamen anzusprechen;
    • Zeile 22: Die Konfiguration der Anwendung wird in einem statischen Attribut (Klassenattribut) gespeichert;
    • Zeilen 26–35: Die statische Methode [setUpBeforeClass] von [TestCase] wird einmal vor dem ersten Test der Klasse ausgeführt. Sie liest die Konfigurationsdatei und lädt die Dateien der Anwendung. Der PHP-7-Kurs erledigte diese Aufgabe auf oberster Ebene der Testdatei, außerhalb der Klasse. Mit PHPUnit wird dieser Code ausgeführt, wenn PHPUnit die Datei lädt, also zu einem Zeitpunkt, den wir nicht kontrollieren; die Methode [setUpBeforeClass] ist für diesen Zweck gedacht;
    • Zeile 31: Die Tests der Schicht [dao] benötigen Abhängigkeiten der Steuerberechnung (für die Klasse [DaoTaxWithTaxAdminDataInDatabase]) und der Übertragung (für die Klasse [DaoTransferAdminDataFromJsonFile2Database]). Die beiden Listen werden zusammengeführt, und anschließend entfernt die Funktion [array_unique] die Duplikate;
    • Zeilen 38–45: die Datenquelle: die Beschreibungsdateien der beiden Datenbanken;
    • Zeilen 48–49: Der Test [testTaxAdminData] aus Version 5 wird für jede der beiden Datenbanken einmal ausgeführt;
    • Zeilen 71–83: Dasselbe gilt für den Test der Übertragung der Daten aus der JSON-Datei in die Datenbank.
