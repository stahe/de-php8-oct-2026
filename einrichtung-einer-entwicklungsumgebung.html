    2. Einrichtung einer Entwicklungsumgebung

    Die Skripte wurden in der folgenden Umgebung geschrieben und getestet:

    • eine Webserver-Umgebung aus [Apache] / DBMS [MySQL] / [PHP] 8.5 namens [Laragon];
    • der Editor [Visual Studio Code] und seine Erweiterung [PHP Intelephense];
    • der Abhängigkeitsmanager [Composer], der mit [Laragon] geliefert wird und die vom Kurs verwendeten PHP-Bibliotheken installiert.

    Weitere Werkzeuge (der Mailserver [Mailpit], das DBMS [PostgreSQL] und der Server [Redis]) sind nur für bestimmte Kapitel relevant: Ihre Installation wird in den jeweiligen Kapiteln beschrieben.

    2.1. Installation von Laragon

    [Laragon] ist ein Paket für [Windows] , das mehrere Softwarekomponenten vereint:

    • ein Webserver ([Apache]). Wir verwenden ihn, um Webskripte in PHP zu schreiben;
    • das DBMS [MySQL] ([PostgreSQL] kann ergänzt werden, siehe das Kapitel zu Version 6);
    • die Skriptsprache PHP in mehreren Versionen, darunter Version 8.5;
    • ein [Redis]-Server, der einen Cache für Webanwendungen bereitstellt;
    • das Werkzeug [Composer];
    • ein Kommandozeilen-Terminal, in dem sich alle diese Werkzeuge direkt verwenden lassen.

    [Laragon] kann heruntergeladen werden unter https://laragon.org/download/. Es ist mit allen Funktionen kostenlos nutzbar; gelegentlich erscheint eine Aufforderung, eine Lizenz zu erwerben, um die Entwicklung zu unterstützen, was optional ist. Die Installation ist unkompliziert: Übernehmen Sie einfach die Standardeinstellungen. [Laragon] wird dann im Ordner [C:\laragon] installiert, den wir im Folgenden als <laragon> bezeichnen:

    1
2
3
4
5
6
    C:\laragon
├── bin\        the software: apache, mysql, php, redis, composer…
├── data\       the DBMS data
├── etc\        configuration files
├── tmp\
└── www\        the root of the Apache web server: http://localhost

    Beim Start von [Laragon] erscheint das Hauptfenster:

    • Die Schaltfläche [Démarrer tout] (Alle starten) startet den Webserver [Apache] sowie das DBMS [MySQL]. Das Fenster zeigt dann für jeden der beiden an, dass er aktiv ist und auf welchem Port er lauscht: 80 für [Apache], 3306 für [MySQL];
    • die Schaltfläche [Web] zeigt die Seite [http://localhost] an, die dem Ordner [<laragon>/www] entspricht;
    • die Schaltfläche [Base de données] (Datenbank) startet ein Werkzeug zur Datenbankverwaltung ([HeidiSQL], das mit [Laragon] geliefert wird);
    • die Schaltfläche [Terminal] öffnet ein Befehlsterminal, in dem [php], [composer], [mysql] … direkt verwendet werden können;
    • die Schaltfläche [Racine] (Wurzel) öffnet den [Windows]-Datei-Explorer im Ordner [<laragon>/www]. Dort legen Sie alle Webanwendungen ab, die vom Server [Apache] von [Laragon] verwaltet werden;
    • Ein Rechtsklick in das Fenster (oder auf das Symbol von [Laragon] in der Taskleiste) öffnet das Menü von [Laragon], über das Sie Zugriff auf die Konfigurationseinstellungen der einzelnen Anwendungen haben.

    2.1.1. PHP 8.5 auswählen

    [Laragon] kann mehrere PHP-Versionen enthalten. Die zu verwendende Version wird in seinem Menü im Abschnitt [PHP > Version] ausgewählt. Wählen Sie Version 8.5 (die neueste der 8.5er-Reihe). Sie wird dann sowohl vom Server [Apache] als auch vom Terminalbefehl [php] verwendet.

    Damit der Befehl [php] auch in den Terminals von [VS Code] verwendbar ist, muss sich der PHP-Ordner im PATH von [Windows] befinden. [Laragon] übernimmt das: Menü [Tools > Path > Add Laragon to Path]. Öffnen Sie anschließend ein neues Terminal (bereits geöffnete Terminals bemerken die Änderung nicht) und geben Sie ein:

    1
    > php -v

    Der Befehl sollte die PHP-Version 8.5.x anzeigen.

    2.1.2. PHP für den Kurs konfigurieren

    PHP wird über eine Textdatei namens [php.ini] konfiguriert, die über das Menü von [Laragon] im Abschnitt [PHP > php.ini] erreichbar ist. Während des Kurses muss PHP alle Fehler, Warnungen und Hinweise auf veraltete Funktionen melden. Prüfen Sie, ob die Datei die folgenden Zeilen enthält (oder ändern Sie sie entsprechend):

    1
2
3
4
5
6
    error_reporting = E_ALL
display_errors = On
display_startup_errors = On
log_errors = On
error_log = C:/laragon/tmp/php_errors.log
date.timezone = Europe/Paris
    • [error_reporting = E_ALL]: PHP meldet alles, einschließlich der [Deprecated]-Meldungen, die veraltete Funktionen ankündigen. Eine Produktivkonfiguration verwendet häufig [E_ALL & ~E_DEPRECATED], was diese ausblendet: Das ist hier nicht gewünscht;
    • [display_errors = On]: Die Meldungen werden in der Ausgabe des Skripts angezeigt (im Terminal oder auf der Webseite);
    • [log_errors = On]: Die Meldungen werden zusätzlich in das Fehlerprotokoll geschrieben;
    • [error_log]: die Protokolldatei. Ohne diese Zeile schreibt ein Konsolenskript sein Protokoll in das Terminal selbst, und jede Meldung würde dort doppelt erscheinen (einmal mit vorangestelltem [PHP], einmal ohne);
    • [date.timezone]: die Zeitzone, die von den Datumsfunktionen verwendet wird.

    Der Kurs verwendet außerdem mehrere Erweiterungen von PHP. Sie werden im Menü von [Laragon] im Abschnitt [PHP > Extensions] oder in der Datei [php.ini] mit Zeilen der Form [extension=name] aktiviert. Verwendet werden die Erweiterungen [curl], [mbstring], [openssl], [pdo_mysql], [pdo_pgsql], [fileinfo] und [zip] (Letztere wird von [Composer] verwendet, um die heruntergeladenen Bibliotheken zu entpacken). Nach einer Änderung der Datei [php.ini] müssen Sie [Apache] neu starten (die Schaltfläche [Reload] in [Laragon]); die Konsolenskripte hingegen lesen die Datei [php.ini] bei jeder Ausführung neu ein.

    Sie können die Konfiguration in einem Terminal mit dem Befehl [php --ini] (die verwendete Datei [php.ini]) und mit [php -m] (die Liste der geladenen Erweiterungen) überprüfen. Das erste Skript des nächsten Kapitels, [phpinfo.php], zeigt die gesamte Konfiguration an.

    2.2. Installation von VS Code

    [Visual Studio Code] ist ein kostenloser Editor von Microsoft, der zum Download bereitsteht unter https://code.visualstudio.com/. Er ersetzt hier die IDE [NetBeans], die im PHP-7-Kurs verwendet wurde.

    Sobald [VS Code] installiert ist, fügen Sie Unterstützung für die Sprache PHP hinzu: Suchen Sie im Bereich [Extensions] (Strg+Umschalt+X) nach der Erweiterung [PHP Intelephense] und installieren Sie sie. Sie bietet:

    • Code-Vervollständigung: PHP-Funktionen, Klassen, ihre Methoden und ihre Attribute werden während der Eingabe vorgeschlagen;
    • Anzeige der Dokumentation einer Funktion oder Methode, wenn Sie mit der Maus über ihren Namen fahren;
    • Fehlererkennung während der Eingabe (nicht definierte Variablen, falsche Typen, nicht vorhandene Methoden usw.), die im Code unterstrichen und im Bereich [Problems] aufgelistet werden;
    • Code-Navigation: Ein Strg+Klick auf einen Klassen- oder Funktionsnamen öffnet seine Definition, auch bei den Bibliotheken im Ordner [vendor].

    [Intelephense] muss die verwendete PHP-Version kennen, um deren Neuerungen zu erkennen: Suchen Sie in den Einstellungen von [VS Code] (Strg+Komma) nach „intelephense php version“ und geben Sie 8.5 ein.

    Öffnen Sie als Nächstes den Code-Ordner des Kurses in [VS Code] (Menü [File > Open Folder]). Über das Menü [Terminal > New Terminal] öffnet sich ein Terminal: Es ist auf den geöffneten Ordner eingestellt, und Sie geben die Befehle [php], [composer], [curl] … ein. Um ein Konsolenskript auszuführen, wechseln Sie in seinen Ordner (Befehl [cd]) und geben [php script-name.php] ein.

    2.4. Installation von Bibliotheken mit Composer

    Wie die meisten Programmiersprachen hat PHP einen Abhängigkeitsmanager, [Composer], der die Bibliotheken, die ein Projekt benötigt, aus dem Repository [packagist.org] herunterlädt. Die vom Kurs verwendeten Bibliotheken sind in der Datei [composer.json] im Ordner [php8-oct-2026] deklariert:

    {
    "name": "stahe/php8-oct-2026",
    "description": "Code of the course \"Introduction to the PHP 8 language by example\" (October 2026)",
    "type": "project",
    "license": "MIT",
    "require": {
        "php": ">=8.5",
        "symfony/http-foundation": "^8.0",
        "symfony/http-client": "^8.0",
        "symfony/mailer": "^8.0",
        "symfony/mime": "^8.0",
        "predis/predis": "^3.0",
        "zbateson/mail-mime-parser": "^3.0"
    },
    "require-dev": {
        "phpunit/phpunit": "^12.0"
    },
    "config": {
        "sort-packages": true
    }
}
    • Zeile 6: die Bibliotheken, die zum Ausführen der Skripte erforderlich sind. Jede wird durch einen Namen der Form [vendor/library] und eine Versionsbeschränkung identifiziert: [^8.0] bedeutet „jede Version 8.x ab 8.0“. Ihre Aufgaben werden in den Kapiteln beschrieben, die sie verwenden;
    • Zeile 7: Das Projekt erfordert PHP 8.5 oder höher;
    • Zeile 15: Bibliotheken, die ausschließlich für die Entwicklung verwendet werden, hier das Testframework [PHPUnit].

    Um diese Bibliotheken zu installieren, öffnen Sie ein Terminal im Ordner [php8-oct-2026] (das Terminal von [Laragon] oder das Terminal von [VS Code]) und geben Sie ein:

    1
    > composer install

    [Composer] erstellt dann einen Ordner namens [vendor] mit den Bibliotheken und ihren Abhängigkeiten sowie eine Datei namens [vendor/autoload.php]. Ein Skript, das diese Bibliotheken nutzen möchte, muss lediglich diese Datei einbinden, die ihre Klassen bei der ersten Verwendung automatisch lädt. Die Skripte dieses Kurses tun dies über einen Pfad relativ zu ihrem eigenen Ordner, zum Beispiel:

    1
    require_once __DIR__ . '/../../vendor/autoload.php';

    Die Konstante [__DIR__] bezeichnet den Ordner des Skripts, das sie verwendet: Der Pfad hängt daher weder von dem Ordner ab, in dem das Skript ausgeführt wird, noch davon, wo sich der Ordner [php8-oct-2026] befindet.

    Überprüfen Sie die Installation, indem Sie die Version von [PHPUnit] anzeigen:

    1
2
    > php vendor/bin/phpunit --version
PHPUnit 12.5.37 by Sebastian Bergmann and contributors.
